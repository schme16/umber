# Naming

**Working name: Umber** (chosen 2026-11-20, "for now, we may circle back another day").
Umber is a warm earth pigment that sits beside the amber accent, it's short, and it works
as a command name (`umber model.glb`). The project, crate, window title, folder and board
all use it. None of the names below have been checked for trademarks, crates.io names or
domains yet.

## Round 1

Umber, Veneer, Livery, Gesso, Burnish, Patina, Lacquer, Ochre, Inlay, Swatch.
The user liked the direction of **Veneer, Livery and Lacquer**.

## Round 2 (finishes and decorative surfaces)

Urushi, Ormolu, Shellac, Enamel, Marquetry, Blazon, Gilt, Coachline, Sheen, Burl.
**Veneer** and **Urushi** came closest ("not terrible"), but nothing clicked.

## Round 3 (four different directions)

- Craft words in other languages: Lasur, Vernis, Raden, Maki-e
- Dressing the model: **Pelt** (pelt mapping is a real UV unwrapping technique), Mantle, Tailor
- The brushstroke: Dab, Daub
- Made-up words: Lacca, Livra, Veneo

## Avoided because they're taken

Graphite (a Rust graphics editor), Glaze (an art-protection tool), Fresco (Adobe),
Armor (too close to ArmorPaint), Varnish (Varnish Cache), Lustre (a filesystem),
Shellac (a CND nail polish brand).
